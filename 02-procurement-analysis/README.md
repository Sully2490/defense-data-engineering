# 02 - Procurement Analysis

Aggregation and analysis of federal spending and procurement data to surface trends across agencies, vendors, and contract categories.

## Overview

This project builds analytical datasets from federal procurement records, enabling spending trend analysis, vendor concentration metrics, and agency-level budget tracking.

## Data Sources

- **USAspending.gov** - Federal spending data
- **FPDS** - Federal Procurement Data System

## Tech Stack

Python, SQL, PostgreSQL, Airflow, AWS (S3, Athena, Lambda), Docker, Terraform

`Planned`
